2º Ciclo ESO y Bachillerato
Una ecuación bicuadrada es una ecuación de grado 4 que solo tiene exponentes pares: a·x⁴ + b·x² + c = 0. Descubre por qué el cambio de variable funciona y cómo aplicarlo a tricuadradas y expresiones complejas.

¿Por qué inventamos el Cambio de Variable?

El Motivo Pedagógico
No sabemos resolver grado 4, pero sí grado 2

No existe una fórmula rápida para ecuaciones con x⁴. Sin embargo, sabemos que por propiedades de las potencias: x⁴ = (x²)². Si le ponemos un «disfraz» temporal a x² llamándolo z, transformamos una ecuación compleja de grado 4 en una simple ecuación de 2º grado.

Ejemplo guiado: x⁴ - 13x² + 36 = 0
Paso 1
Aplicar el cambio de variable
Hacemos: z = x²  ➔  Por tanto: z² = (x²)² = x⁴
La ecuación queda: z² - 13z + 36 = 0
Paso 2
Resolver la ecuación de 2º grado en z
a = 1, b = -13, c = 36
z = [ -(-13) ± √(-13)² - 4·1·36 ] / (2·1)
z = [ 13 ± √169 - 144 ] / 2 = [ 13 ± √25 ] / 2 = [ 13 ± 5 ] / 2

➔ z₁ = (13 + 5)/2 = 18/2 = 9
➔ z₂ = (13 - 5)/2 = 8/2 = 4
Paso 3 (Crucial)
Deshacer el cambio para encontrar la x

El problema pedía hallar x, no z. Como z = x², despejamos haciendo x = ±√z:

• Con z₁ = 9  ➔  x² = 9  ➔  x = ±√9 = ±3
• Con z₂ = 4  ➔  x² = 4  ➔  x = ±√4 = ±2
Solución final: 4 soluciones reales ➔ x = { -3, -2, 2, 3 }

Ecuaciones Tricuadradas (Grado 6)

¿Qué ocurre cuando aparecen potencias como x⁶ y x³? Sigue siendo la misma estrategia, porque x⁶ = (x³)².

Ejemplo guiado: x⁶ - 7x³ - 8 = 0
Paso 1: Adaptar el cambio
Hacemos: z = x³  ➔  z² = (x³)² = x⁶
La ecuación se transforma en: z² - 7z - 8 = 0
Paso 2: Resolver en z
z = [ 7 ± √(-7)² - 4·1·(-8) ] / 2
z = [ 7 ± √49 + 32 ] / 2 = [ 7 ± √81 ] / 2 = [ 7 ± 9 ] / 2

➔ z₁ = (7 + 9)/2 = 16/2 = 8
➔ z₂ = (7 - 9)/2 = -2/2 = -1
Paso 3: Deshacer con Raíz Cúbica

Como z = x³, aplicamos la raíz cúbica: x = 3√z (las raíces de índice impar sí admiten radicandos negativos):

• Con z₁ = 8  ➔  x = 3√8 = 2
• Con z₂ = -1  ➔  x = 3√-1 = -1
Solución final: 2 soluciones reales ➔ x₁ = 2, x₂ = -1

Bicuadradas Camufladas (Simplificar Primero)

En muchos exámenes la bicuadrada no viene servida. Primero hay que eliminar denominadores y agrupar términos.

Ejemplo de examen: x² - 1 = 24 / (x² + 1)
Paso 1: Quitar denominadores

Multiplicamos ambos miembros por el denominador (x² + 1):

(x² - 1) · (x² + 1) = 24
Paso 2: Reconocer Identidad Notable

Tenemos una suma por diferencia: (a - b)(a + b) = a² - b²:

(x²)² - (1)² = 24
x⁴ - 1 = 24
x⁴ - 25 = 0
Paso 3: Resolver la Bicuadrada Incompleta
Despejamos directamente:
x⁴ = 25
x = ± 4√25 = ± √√25 = ± √5

➔ x₁ = +√5 ≈ +2,236
➔ x₂ = -√5 ≈ -2,236
