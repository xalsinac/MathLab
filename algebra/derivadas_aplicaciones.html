Puntos Singulares (Críticos) y Monotonía

¿Qué es un Punto Singular?
La recta tangente se vuelve completamente plana (horizontal, m = 0)

Los puntos donde la primera derivada se anula, f'(x) = 0, son los candidatos a cimas (máximos), valles (mínimos) o descansos planos (puntos de inflexión de tangente horizontal).

Curva f(x) = 2x³ - 3x² - 12x + 1 Máximo Relativo (-1, 8) [f'=0] Mínimo Relativo (2, -19) [f'=0]
Procedimiento de Examen: Hallar intervalos de crecimiento y extremos
Dada f(x) = 2x³ - 3x² - 12x + 1:

1. Derivar e igualar a cero:
f'(x) = 6x² - 6x - 12 = 0  ➔  x² - x - 2 = 0
Resolviendo: x₁ = -1  y  x₂ = 2 (Puntos singulares).

2. Tabla de signos de f'(x) dividiendo la recta real:
Intervalo (-∞, -1) x = -1 (-1, 2) x = 2 (2, +∞)
Signo de f'(x) + (f'(-2) = 24 > 0) f' = 0 - (f'(0) = -12 < 0) f' = 0 + (f'(3) = 24 > 0)
Comportamiento f(x) CRECIENTE ↗ MÁXIMO DECRECIENTE ↘ MÍNIMO CRECIENTE ↗
3. Calcular las coordenadas Y sustituyendo en la función original f(x):
• f(-1) = 2(-1)³ - 3(-1)² - 12(-1) + 1 = -2 - 3 + 12 + 1 = 8  ➔  Máximo en (-1, 8)
• f(2) = 2(2)³ - 3(2)² - 12(2) + 1 = 16 - 12 - 24 + 1 = -19  ➔  Mínimo en (2, -19)

La Segunda Derivada: Curvatura e Inflexión

El Criterio Rápido de la Segunda Derivada para Extremos
¿Cómo saber si un punto crítico x₀ es máximo o mínimo sin hacer la tabla?
Calculamos f''(x₀) en el punto singular:
• Si f''(x₀) < 0 ➔ Curva convexa / cóncava hacia abajo ➔ MÁXIMO RELATIVO ∩
• Si f''(x₀) > 0 ➔ Curva cóncava / cóncava hacia arriba ➔ MÍNIMO RELATIVO ∪
• Si f''(x₀) = 0 ➔ El criterio no decide (hay que mirar derivadas superiores o tabla).
Puntos de Inflexión: Donde cambia la curvatura
Condición necesaria: f''(x) = 0 y f'''(x) ≠ 0

Un Punto de Inflexión es el lugar geométrico exacto donde la gráfica pasa de cóncava a convexa (o viceversa), y la recta tangente atraviesa la función.

Siguiendo con f(x) = 2x³ - 3x² - 12x + 1:
1. f'(x) = 6x² - 6x - 12
2. Segunda derivada: f''(x) = 12x - 6
3. Igualamos a cero: 12x - 6 = 0 ➔ 12x = 6 ➔ x = 1/2 = 0,5
4. Como f'''(x) = 12 ≠ 0, se confirma que es punto de inflexión.
5. Coordenada Y: f(0,5) = 2(0,125) - 3(0,25) - 12(0,5) + 1 = 0,25 - 0,75 - 6 + 1 = -5,5

Punto de Inflexión en P(0.5, -5.5)

Protocolo Maestro de Representación Gráfica

En los exámenes de Selectividad, la representación gráfica se corrige siguiendo una rúbrica estricta en 6 etapas:

1. Dominio y Simetría
• Buscar puntos que anulan denominadores o hacen negativos los radicandos pares.
• Simetría par: f(-x) = f(x) (simétrica respecto al eje Y).
• Simetría impar: f(-x) = -f(x) (simétrica respecto al origen O).
2. Puntos de Corte con los Ejes
• Con el eje Y: Hacemos x = 0 ➔ (0, f(0)).
• Con el eje X: Resolvemos f(x) = 0 ➔ (x₁, 0), (x₂, 0).
3. Ramas Infinitas y Asíntotas
• Asíntota Vertical (A.V.): En los puntos fuera del dominio x = a donde lim (x ➔ a) f(x) = ±∞.
• Asíntota Horizontal (A.H.): y = k si lim (x ➔ ±∞) f(x) = k.
• Asíntota Oblicua (A.O.): y = mx + n (solo si no hay horizontal y grado numerador = grado denominador + 1):
   m = lim (x ➔ ∞) f(x)x      n = lim (x ➔ ∞) [ f(x) - m·x ]
4. Monotonía y Extremos (Primera Derivada)
Resolver f'(x) = 0, montar la tabla de intervalos y señalar los máximos y mínimos relativos.
5. Curvatura e Inflexión (Segunda Derivada)
Resolver f''(x) = 0 para detectar los cambios de curvatura y puntos de inflexión.

Problemas de Optimización (El Clásico de Selectividad)

El Método Infalible en 4 Pasos
1. Identificar la función objetivo: ¿Qué queremos maximizar o minimizar? (Área, volumen, coste, tiempo...).
2. Ecuación de ligadura (restricción): Expresar una relación entre las variables (perímetro fijo, volumen dado...).
3. Despejar y reducir a una sola variable: Sustituir en la función objetivo para obtener f(x).
4. Derivar, igualar a cero y comprobar con f'': Hallar el punto crítico y verificar con la segunda derivada si es el extremo buscado.
Problema Modelo Resuelto: El Vallado Óptimo
«Se dispone de 200 metros de tela metálica para cercar un terreno rectangular. ¿Cuáles deben ser sus dimensiones para que el área encerrada sea máxima?»
Paso 1: Variables y función a maximizar:
Sean x la base e y la altura del rectángulo.
Queremos que el área sea máxima: Área = x · y  (Fórmula con 2 variables)

Paso 2: Condición de ligadura (Perímetro = 200 m):
2x + 2y = 200 ➔ Dividiendo entre 2: x + y = 100 ➔ y = 100 - x

Paso 3: Reducir la función área a una sola variable A(x):
A(x) = x · (100 - x) = 100x - x²

Paso 4: Derivar e igualar a cero para hallar el máximo:
A'(x) = 100 - 2x = 0 ➔ 2x = 100 ➔ x = 50 m

Paso 5: Comprobación con la segunda derivada:
A''(x) = -2 < 0 ➔ Es un MÁXIMO ABSOLUTO indiscutible.

Paso 6: Dimensiones y Área Máxima:
• Altura: y = 100 - 50 = y = 50 m
• Área máxima: A = 50 · 50 = 2.500 m²

Conclusión geométrica: El rectángulo de área máxima siempre es un CUADRADO.
