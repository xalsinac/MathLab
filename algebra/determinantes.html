2º Bachillerato
El determinante es un número escalar único asignado a cada matriz cuadrada. Es la herramienta definitiva para comprobar si una matriz tiene inversa, calcular el rango (independencia lineal) y discutir sistemas mediante el Teorema de Rouché-Fröbenius.

Determinants d'Ordre 2 i 3

Determinant d'Ordre 2 (2 × 2)
Producte de la diagonal principal menys la secundària
|A| = ab cd = a · d - b · c
Exemple: |A| = 3-2 54 = (3 · 4) - (-2 · 5) = 12 - (-10) = 12 + 10 = 22
Determinante 3 × 3: Regla de Sarrus (Método de Filas Extendidas)
Repetimos las dos primeras filas abajo y trazamos diagonales rectas

El truco más fácil para no equivocarse con los triángulos: copiamos la Fila 1 y la Fila 2 debajo de la matriz. Todas las operaciones se convierten en líneas diagonales rectas continuas de 3 números.

Propietats Fonamentals (Trucs de Selectivitat)

Conèixer aquestes propietats permet calcular determinants d'ordre superior sense desenvolupar càlculs llargs i justificar problemes teòrics.

1. Quan un determinant val ZERO exactament?
El determinant d'una matriu quadrada val 0 (|A| = 0) si:
• Té una fila o columna sencera de zeros.
• Té dues files o columnes idèntiques.
• Té dues files o columnes proporcionals (ex: F₂ = 3 · F₁).
• Una fila és combinació lineal d'altres files (ex: F₃ = F₁ + 2·F₂).
2. Operacions entre Files i Columnes
• Permutar dues files: El determinant canvia de signe.
   |F₂, F₁, F₃| = - |F₁, F₂, F₃|

• Multiplicar una fila per un nombre k: El determinant queda multiplicat per k.
   |k·F₁, F₂, F₃| = k · |F₁, F₂, F₃|
   Atenció en Selectivitat: Si la matriu A és n × n, llavors |k · A| = kⁿ · |A|.

• Sumar a una fila una combinació d'altres files: El valor del determinant NO canvia (la base del mètode de Gauss per fer zeros).
3. Propietats de la Transposada, Producte i Inversa
• Transposició: El determinant d'una matriu i el de la seva transposada són idèntics:
   |Aᵗ| = |A|

• Producte de matrius: El determinant del producte és el producte dels determinants:
   |A · B| = |A| · |B|

• Determinant de la inversa: Com que A · A⁻¹ = I i |I| = 1:
   |A⁻¹| = 1|A|    (sempre que |A| ≠ 0)

Rang d'una Matriu mitjançant Determinants (Menors)

Concepte de Menor i Definició de Rang
El rang és l'ordre del menor més gran no nul

Un menor d'ordre k és el determinant d'una submatriu quadrada k × k obtinguda eliminant certes files i columnes de la matriu original.

Rang(A) = r significa que existeix com a mínim un menor d'ordre r que no s'anul·la (≠ 0), i tots els menors d'ordre superior (r+1) valen 0.
Algorisme d'«Orlar» Menors pas a pas
Exemple: Trobar el rang d'una matriu 3 × 4
Sigui A = 1230 2461 102-1

Paso 1: Buscar un menor d'ordre 1 no nul:
|1| = 1 ≠ 0 ➔ Rang(A) ≥ 1.

Paso 2: Buscar un menor d'ordre 2 no nul afegint fila i columna (orlar):
Prenem les files 1, 3 i columnes 1, 2:
12 10 = (1·0) - (2·1) = -2 ≠ 0 ➔ Rang(A) ≥ 2.

Paso 3: Orlar el menor 2×2 anterior amb la fila restant (F₂) i les columnes 3 i 4:
• Amb Columna 3 (Files 1, 2, 3 i Cols 1, 2, 3):
123 246 102 = 0  (Fila 2 és proporcional a Fila 1: [2, 4, 6] = 2·[1, 2, 3]).

• Amb Columna 4 (Files 1, 2, 3 i Cols 1, 2, 4):
120 241 10-1 = (1·4·(-1) + 2·1·1 + 0) - (0 + 1·0 + 2·2·(-1)) = (-4 + 2) - (-4) = -2 + 4 = 2 ≠ 0.

Com hem trobat un menor 3×3 diferent de zero: Rang(A) = 3.

La Matriu Inversa mitjançant Determinants

Condició d'Existència de la Inversa (Teorema)
Una matriu A té inversa (és invertible o regular) si i només si |A| ≠ 0

Si |A| = 0, la matriu s'anomena singular i no té inversa.

Fórmula General d'Inversió
A⁻¹ = 1|A| · [ Adj(A) ]ᵗ

On l'adjunt d'un element és: A_ij = (-1)^(i+j) · M_ij (el menor eliminant la fila i i columna j).

Exemple Complet 3 × 3 resolt pas a pas
Sigui A = 102 2-13 418

Paso 1: Calcular el determinant de A:
|A| = [ 1·(-1)·8 + 0·3·4 + 2·2·1 ] - [ 2·(-1)·4 + 1·3·1 + 0·2·8 ]
|A| = [ -8 + 0 + 4 ] - [ -8 + 3 + 0 ] = (-4) - (-5) = 1 (Com |A| = 1 ≠ 0, existeix A⁻¹)

Paso 2: Calcular la matriu d'adjunts Adj(A) considerant el tauler de signes:
Tauler de signes: +-+ -+- +-+
• A₁₁ = + |(-1·8) - (3·1)| = -8 - 3 = -11
• A₁₂ = - |(2·8) - (3·4)| = -(16 - 12) = -4
• A₁₃ = + |(2·1) - (-1·4)| = 2 - (-4) = 6
• A₂₁ = - |(0·8) - (2·1)| = -(0 - 2) = 2
• A₂₂ = + |(1·8) - (2·4)| = 8 - 8 = 0
• A₂₃ = - |(1·1) - (0·4)| = -(1 - 0) = -1
• A₃₁ = + |(0·3) - (2·(-1))| = 0 - (-2) = 2
• A₃₂ = - |(1·3) - (2·2)| = -(3 - 4) = 1
• A₃₃ = + |(1·(-1)) - (0·2)| = -1 - 0 = -1

Adj(A) = -11-46 20-1 21-1

Paso 3: Transposar la matriu d'adjunts [Adj(A)]ᵗ:
[Adj(A)]ᵗ = -1122 -401 6-1-1

Paso 4: Multiplicar per 1 / |A| (com |A| = 1, queda idèntica):
A⁻¹ = -1122 -401 6-1-1
