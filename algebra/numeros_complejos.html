1º Bachillerato Científico
¿Qué ocurre cuando intentamos resolver x² + 1 = 0? Durante siglos se consideró un callejón sin salida. Los números complejos amplían la recta real unidimensional a un plano bidimensional, permitiendo resolver cualquier ecuación algebraica y modelar ondas, electromagnetismo y mecánica cuántica.

La Unidad Imaginaria (i)

El Nacimiento de los Imaginarios
Resolver lo imposible: Raíces cuadradas de números negativos

Ningún número real al cuadrado da un resultado negativo: (+2)² = +4 y (-2)² = +4. Para resolver x² = -1, definimos un nuevo número llamado unidad imaginaria i:

i = √-1     ➔     i² = -1

Ahora cualquier raíz negativa se descompone de forma limpia:
√-9 = √9 · (-1) = √9 · √-1 = ±3i.

Ciclo Periódico de las Potencias de i
Multiplicar por i equivale geométricamente a girar 90° en el plano
• i⁰ = 1
• i¹ = i
• i² = -1
• i³ = i² · i = (-1) · i = -i
• i⁴ = i² · i² = (-1) · (-1) = 1  (¡El ciclo se repite cada 4 pasos!)
¿Cómo calcular potencias elevadas (ej: i¹³⁵)?
Dividimos el exponente entre 4 y nos quedamos con el resto:
135 ÷ 4 = cociente 33 con resto 3.
➔ i¹³⁵ = i³ = -i

El Plano Complejo (Argand): Forma Binómica y Polar

Un número complejo z no cabe en la recta numérica real. Necesita dos dimensiones: un Eje Real horizontal (Re) y un Eje Imaginario vertical (Im).

Las Dos Formas de Representación
• Forma Binómica: z = a + bi   (a = parte real, b = parte imaginaria)
• Forma Polar: z = rα   (r = módulo, α = argumento)
Laboratorio Vectorial: De Binómica a Polar en Tiempo Real
Fórmulas de Conversión Directa
1. Módulo (Teorema de Pitágoras): r = |z| = √a² + b²
2. Argumento (Trigonometría): α = arctan( ba )  (ajustando según el cuadrante: +180° si a < 0)
3. Paso de Polar a Binómica (Forma Trigonométrica): a = r · cos(α)  |  b = r · sen(α)

Operaciones con Números Complejos

1. Operaciones en Forma Binómica (Suma, Resta y División)
• Suma y Resta: Se suman o restan componentes reales entre sí e imaginarias entre sí:
   (3 + 2i) + (1 - 5i) = (3 + 1) + (2 - 5)i = 4 - 3i

• Conjugado: Dado z = a + bi, su conjugado es z̄ = a - bi (simétrico respecto al eje real).

• División: Se multiplica numerador y denominador por el conjugado del divisor para eliminar la i del denominador:
   2 + 3i1 - i = (2 + 3i) · (1 + i)(1 - i) · (1 + i) = 2 + 2i + 3i + 3i²1² - i² = 2 + 5i - 31 - (-1) = -1 + 5i2 = -0,5 + 2,5i
2. Multiplicación y División en Forma Polar: La Ventaja Geométrica
En polar, multiplicar es girar y escalar
Sean dos complejos en polar: z₁ = (r₁)α  y  z₂ = (r₂)β:

• Producto: z₁ · z₂ = (r₁ · r₂)α + β

• Cociente: z₁z₂ = ( r₁r₂ )α - β    z₁z₂ = ( r₁r₂ )_{α - β}
3. Potencias: Fórmula de De Moivre
Calcular (1 + i)¹⁰ sin desarrollar binomios interminables

Elevar a una potencia n en forma polar es directo: el módulo se eleva a la potencia y el ángulo se multiplica por n:

( rα )n = (rn)n · α = rn · [ cos(nα) + i · sen(nα) ]
Ejemplo: z = 1 + i ➔ Módulo r = √1² + 1² = √2 ; Ángulo α = 45° ➔ z = (√2)45°

z⁶ = [ (√2)45° ]⁶ = [ (√2)⁶ ]6 · 45° = 8270° = -8i

La Fórmula y la Identidad de Euler

La Fórmula de Euler
Conectar la función exponencial con la trigonometría

Leonhard Euler demostró que la base natural e elevada a un exponente imaginario traza una trayectoria circular en el plano complejo:

e^(iθ) = cos(θ) + i · sen(θ)

Esto permite expresar cualquier número complejo en forma exponencial: z = r · e^(iα).

La Identidad Más Bella de las Matemáticas
¿Qué ocurre cuando el ángulo es exactamente π radianes (180°)?
Sustituyendo θ = π en la fórmula de Euler:
e^(iπ) = cos(π) + i · sen(π)
Como cos(π) = -1 y sen(π) = 0:
e^(iπ) = -1 + 0i = -1

Pasando el 1 sumando al miembro izquierdo obtenemos:
e^(iπ) + 1 = 0
Esta fórmula unifica las 5 constantes capitales del universo matemático en una sola ecuación:
  • e: La base del cálculo y del crecimiento natural.
  • i: La unidad imaginaria del álgebra.
  • π: La constante geométrica del círculo.
  • 1: El elemento neutro de la multiplicación.
  • 0: El elemento neutro de la suma.
