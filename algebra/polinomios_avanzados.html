Polinomios Avanzados

Domina las fracciones algebraicas, la división tradicional por caja, el arte de sacar factor común y la simplificación mediante identidades notables.

¿Por qué NO son polinomios?
Un polinomio solo permite sumar, restar y multiplicar variables con exponentes enteros y positivos. Cuando una variable (como la x) aparece en el denominador o dentro de una raíz, el objeto cambia de nombre: es una Fracción Algebraica.
Polinomios Permitidos (✓)

Aquí la variable x solo está arriba, multiplicándose o elevándose a números naturales:

3x² - 5x + 1 ✓ El exponente es 2 (natural), no hay divisiones por x.
x³ - 45 + 2x ✓ Ojo: que esté dividido por 5 (un número) es legal. No hay 'x' en el denominador.
Fracciones Algebraicas (✖ NO son Polinomios)

En cuanto hay una división por la variable x, todo se altera porque el denominador podría valer 0:

2x + 1x - 3 ✖ La 'x' está en el denominador. Si x = 3, estaríamos dividiendo entre cero (imposible matemáticamente).
🚨 La Gran Diferencia: Un polinomio se puede evaluar para cualquier número. Una fracción algebraica tiene "zonas prohibidas" (los números que hacen 0 el denominador).
El algoritmo de toda la vida
Dividir polinomios es calcado a la división de números naturales con caja que hacías en primaria, pero respetando las columnas de cada grado: x³, x², x y término independiente.

Pizarra de Transformación
💡 ¡Aviso de examen!: Si tienes x² + x y sacas factor común la x, ¡el segundo término NO se convierte en 0! Al dividir x / x queda 1:
x² + x = x · (x + 1)
"Cortar" lo que sea idéntico arriba y abajo
Para simplificar una fracción algebraica, está terminantemente prohibido tachar términos sueltos que estén sumando. Primero debemos FACTORIZAR (usando factor común o identidades notables) para conseguir multiplicaciones, y luego cancelar los paréntesis idénticos.
El Ejemplo Paso a Paso

Simplifiquemos la fracción:

x² - 4x x² - 16
Paso 1: Factorizar el Numerador (Arriba)

Vemos que x² y 4x comparten x. Sacamos factor común:
➔ x · (x - 4)

Paso 2: Factorizar el Denominador (Abajo)

Reconocemos una identidad notable (Diferencia de cuadrados, a² - b²):
x² - 16 = x² - 4² ➔ (x + 4) · (x - 4)

Paso 3: Cancelar factores idénticos

Sustituimos y cancelamos el paquete (x - 4) que se multiplica en ambos lados:

x · (x - 4) (x + 4) · (x - 4) = x x + 4
🚨 ¡El delito matemático número uno!
¿Por qué NO se puede hacer esto?

x + 2 x + 4 ≠ 2 4
Las sumas actúan como bloques de cemento. No puedes romper una suma.

Comprobación numérica rápida: Si x = 10, la izquierda da 12/14, pero la derecha da 2/4. ¡No tiene nada que ver! Solo se cancela cuando está todo multiplicando.
