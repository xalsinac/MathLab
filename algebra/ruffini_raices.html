Raíces y Regla de Ruffini

Aprende a encontrar las raíces de un polinomio, a factorizarlo mediante la Regla de Ruffini y a resolver ecuaciones polinómicas igualadas a cero.

El Número Destructor (El que da Cero)
Una raíz de un polinomio es un número que, al sustituirlo por la x y hacer las operaciones, hace que todo el polinomio valga exactamente 0. Gráficamente, es el punto donde la curva del polinomio corta el suelo (el eje X).
Comprobación Visual

Tenemos el polinomio: P(x) = x² - 5x + 6

Probamos con x = 1:
P(1) = (1)² - 5(1) + 6 = 1 - 5 + 6 = 2
✖ No da cero. El 1 NO es una raíz.
Probamos con x = 2:
P(2) = (2)² - 5(2) + 6 = 4 - 10 + 6 = 0
✓ Da exactamente cero. El 2 es una RAÍZ.
El Teorema del Factor
Si descubres que un número a es una raíz, automáticamente sabes que el polinomio se puede dividir de forma exacta (resto cero) entre el paquete (x - a).

En nuestro ejemplo, como el 2 es una raíz, sabemos seguro que P(x) se puede dividir entre (x - 2).

* Ojo al cambio de signo: Si la raíz es 2, el factor es (x - 2). Si la raíz fuera -3, el factor sería (x + 3).

La Cruz Mágica para Dividir y Factorizar
La Regla de Ruffini es un atajo visual para dividir polinomios entre factores del tipo (x - a). No solo nos dice si la división es exacta, sino que nos devuelve los coeficientes del nuevo polinomio factorizado.

La Propiedad del Producto Cero
Si tienes una ecuación donde varios "paquetes" (factores) se multiplican y el resultado final es 0, la regla de oro es: para que una multiplicación dé cero, al menos uno de los paquetes tiene que valer cero por obligación.
1. Dos Paréntesis
(x - 5) · (x + 3) = 0

Igualamos cada "paquete" a cero para encontrar las dos raíces que destruyen la ecuación:

Si el 1º vale 0:
x - 5 = 0 ➔ x₁ = 5
Si el 2º vale 0:
x + 3 = 0 ➔ x₂ = -3
2. La trampa de la 'x' suelta
x · (x - 4) = 0
⚠️ ¡Nunca pases la 'x' dividiendo al cero! La 'x' suelta es un paquete más con pleno derecho.
Si el 1º vale 0:
x₁ = 0
Si el 2º vale 0:
x - 4 = 0 ➔ x₂ = 4
3. Factores múltiples
3x · (x + 2) · (x - 1) = 0

El 3 delante no afecta (3 nunca puede ser 0). Tenemos 3 paquetes con 'x', luego habrá 3 soluciones:

x₁ = 0 (Si 3x=0, x=0)
x₂ = -2
x₃ = 1
