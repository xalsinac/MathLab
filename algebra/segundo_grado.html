Ecuaciones de 2º Grado

Aprende a identificar la forma canónica, resolver ecuaciones incompletas, aplicar la fórmula de Bhaskara y entender gráficamente sus soluciones.

¿Qué es una ecuación de 2º grado?
Es una igualdad donde la incógnita x está elevada como máximo al cuadrado (x²). Para resolverla, el primer paso siempre es ordenarla e igualarla a cero.
Anatomía de los Coeficientes
ax² + bx + c = 0
  • a (Término cuadrático): El número que multiplica a x². ¡Nunca puede ser 0! Si no lleva número escrito (ej: x²), vale 1.
  • b (Término lineal): El número que multiplica a x. Recuerda que su signo forma parte del coeficiente.
  • c (Término independiente): El número suelto sin ninguna letra.
¡Cuidado con el orden y los signos!

Antes de aplicar cualquier fórmula, todos los términos deben estar a un lado igualados a 0.

Desordenada:
3x - 5 + 2x² = 0
Ordenada canónica:
2x² + 3x - 5 = 0  ➔ a=2, b=3, c=-5
Con términos a ambos lados:
x² = 7x - 10
Pasamos todo a la izquierda cambiando signos:
1x² - 7x + 10 = 0  ➔ a=1, b=-7, c=10
Falta la 'b' (ax² + c = 0)

No hay término con x sola. Se resuelve despejando directamente la x² como si fuera una ecuación normal y aplicando la raíz cuadrada al final.

2x² - 18 = 0
1. Pasamos el número: 2x² = 18
2. Pasamos dividiendo: x² = 18 / 2 = 9
3. Raíz cuadrada: x = ± 9
Soluciones: x₁ = 3 , x₂ = -3
* Nota: Si al despejar queda x² = (número negativo), la ecuación no tiene solución.
Falta la 'c' (ax² + bx = 0)

No hay número suelto. Se resuelve sacando factor común la x. Este tipo de ecuación siempre tendrá x=0 como una de sus soluciones.

3x² - 12x = 0
1. Sacamos factor común x:
x · (3x - 12) = 0
2. Para que multiplique cero, uno de los trozos es cero:
• Trozo 1: x₁ = 0
• Trozo 2: 3x - 12 = 0 ➔ 3x = 12 ➔ x₂ = 4

Desarrollo Matemático Riguroso
El detector del número de soluciones
La parte interior de la raíz cuadrada se llama Discriminante y se representa con la letra griega delta: Δ = b² - 4ac. Solo con calcular este valor ya sabemos cuántas soluciones tendrá la ecuación sin necesidad de terminarla.
Δ = b² - 4ac

1. Si Δ > 0 (Positivo)

2 soluciones reales distintas.

La raíz de un número positivo tiene dos resultados posibles (+ y -). Al sumar y restar esa raíz en el numerador, obtenemos dos valores diferentes: x₁ y x₂.

Ej: ±16 = ±4 ➔ x₁ ≠ x₂

2. Si Δ = 0 (Cero)

1 solución real única (doble).

La raíz de 0 es 0. Sumar cero o restar cero da exactamente lo mismo, por lo que las dos soluciones coinciden en el mismo valor:
x = -b2a

Ej: ±0 = 0 ➔ x₁ = x₂

3. Si Δ < 0 (Negativo)

0 soluciones reales (No tiene solución).

No existe ningún número real que al elevarlo al cuadrado dé un número negativo. La raíz no se puede calcular en los números reales y el proceso se detiene ahí.

Ej: -25 = No existe en ℝ
El Significado Visual: Puntos de Corte con y = 0
Una ecuación de 2º grado ax² + bx + c = 0 equivale a representar la función parábola y = ax² + bx + c y buscar dónde corta al eje horizontal X (donde y = 0). Las soluciones de la ecuación son simplemente las coordenadas X de esos puntos de corte.
