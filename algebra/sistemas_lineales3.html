2º Bachillerato
Un sistema lineal de $m$ ecuaciones con $n$ incógnitas describe la intersección geométrica de rectas o planos en el espacio. Aprende a discutir su compatibilidad con el Teorema de Rouché-Fröbenius y a resolverlos de forma exacta mediante Gauss y Cramer.

Teorema de Rouché-Fröbenius y Discusión con Parámetro

Condición de Rangos Tipo de Sistema Número de Soluciones Interpretación Geométrica (3 planos)
rg(A) = rg(A|B) = n SCD (Compatible Determinado) Solución única (x, y, z) Los 3 planos se cortan en un único punto.
rg(A) = rg(A|B) < n SCI (Compatible Indeterminado) Infinitas soluciones (dependen de parámetros) Se cortan en una recta común o son planos coincidentes.
rg(A) < rg(A|B) SI (Incompatible) No tiene solución Planos paralelos o se cortan dos a dos formando un prisma.
Ejercicio Típico de Selectividad: Discusión según el Parámetro k
{
k·x + y + z = 1 x + k·y + z = 1 x + y + k·z = 1
Paso 1: Matriz de coeficientes A y matriz ampliada A|B:
A = k11 1k1 11k      A|B = k111 1k11 11k1

Paso 2: Calcular el determinante de A para hallar los valores críticos:
|A| = k³ + 1 + 1 - (k + k + k) = k³ - 3k + 2
Factorizamos por Ruffini sabiendo que k = 1 anula la expresión:
|A| = (k - 1)² · (k + 2)

Igualamos a cero: |A| = 0 ➔ k = 1  y  k = -2.

Paso 3: Discusión exhaustiva de casos:

• Caso 1: Si k ≠ 1 y k ≠ -2
   |A| ≠ 0 ➔ rg(A) = 3 = rg(A|B) = n. Por Rouché-Fröbenius, es un SCD (Solución única).

• Caso 2: Si k = 1
   Las tres ecuaciones quedan idénticas: x + y + z = 1.
   rg(A) = 1 = rg(A|B) < 3. Por Rouché-Fröbenius, es un SCI (Infinitas soluciones con 2 grados de libertad: un plano).

• Caso 3: Si k = -2
   |A| = 0 ➔ rg(A) < 3. Tomamos un menor 2×2 en A: |(-2·(-2)) - (1·1)| = 3 ≠ 0 ➔ rg(A) = 2.
   Orlamos con la columna de términos independientes en A|B:
   Menor = -211 1-21 111 = 9 ≠ 0 ➔ rg(A|B) = 3.
   Como rg(A) = 2 ≠ rg(A|B) = 3, por Rouché-Fröbenius el sistema es SI (Incompatible, no tiene solución).

Método de Triangulación de Gauss

¿En qué consiste el "Truco" de Gauss?
1. Retirar las letras y 2. Construir un triángulo de ceros

Escribir una y otra vez las incógnitas x, y, z nos hace perder tiempo y espacio. Gauss nos dice: quédate solo con los números (coeficientes) ordenados en una tabla rectangular y separados de los resultados por una barra imaginaria.

Nuestro objetivo absoluto es hacer 3 ceros en la esquina inferior izquierda (debajo de la diagonal principal). Así, la última fila contendrá únicamente la z y podremos despejar todo el sistema en cascada hacia arriba.

¿Qué pasa con los otros casos en Gauss? (No todo es solución única)
Aprende a interpretar la última fila escalonada
Caso A: Sistema Compatible Determinado (SCD)
Queda una ecuación normal con un coeficiente distinto de cero: [ 0   0   a  | b ]  ➔  a·z = b.
Hay una única solución: z = b / a.

Caso B: Sistema Compatible Indeterminado (SCI - Infinitas Soluciones)
Una fila entera se anula por completo: [ 0   0   0  | 0 ]  ➔  0·z = 0.
Esto es una tautología matemática que siempre se cumple (0 = 0). Significa que esa ecuación era redundante.
¿Cómo se responde en el examen? Se elimina esa fila y se pasa una de las incógnitas al segundo miembro como parámetro libre (habitualmente z = λ), despejando x e y en función de λ.

Caso C: Sistema Incompatible (SI - Sin Solución)
La parte izquierda se anula pero la derecha da un número distinto de cero: [ 0   0   0  | k ]  ➔  0·z = k (con k ≠ 0).
Esto es una imposibilidad lógica (0 nunca puede ser igual a 5).
En cuanto veas una fila así en Gauss, detén las operaciones inmediatamente y concluye: «El sistema no tiene solución (SI)».

Regla de Cramer

Solo aplicable a sistemas con el mismo número de ecuaciones que de incógnitas y con |A| ≠ 0 (SCD).

Fórmula de Cramer
x = |Aₓ||A|          y = |A_y||A|          z = |A_z||A|

Donde |Aₓ| es el determinante que resulta de sustituir la columna de las x por la columna de términos independientes B.

Ejemplo Numérico Guiado
{
x + y + z = 6 x - y + z = 2 2x - y + 3z = 9
1. Determinante principal |A|:
|A| = 111 1-11 2-13 = (-3 + 2 - 1) - (-2 - 1 + 3) = (-2) - (0) = -2 ≠ 0 (Podemos aplicar Cramer)

2. Determinante para x (|Aₓ|) (Columna 1 cambiada por [6, 2, 9]):
|Aₓ| = 611 2-11 9-13 = -2  ➔  x = -2-2 = 1

3. Determinante para y (|A_y|) (Columna 2 cambiada por [6, 2, 9]):
|A_y| = 161 121 293 = -4  ➔  y = -4-2 = 2

4. Determinante para z (|A_z|) (Columna 3 cambiada por [6, 2, 9]):
|A_z| = 116 1-12 2-19 = -6  ➔  z = -6-2 = 3

Solución final exacta: (x, y, z) = (1, 2, 3)

Sistemas Homogéneos y Resolución de Problemas

Propiedad de los Sistemas Homogéneos (Términos independientes = 0)
UN SISTEMA HOMOGÉNEO NUNCA PUEDE SER INCOMPATIBLE

Siempre admite como mínimo la solución trivial: (x, y, z) = (0, 0, 0).
• Si |A| ≠ 0 ➔ rg(A) = 3 = n ➔ Solo existe la solución trivial (0, 0, 0).
• Si |A| = 0 ➔ rg(A) < 3 ➔ Existen infinitas soluciones no triviales (se parametriza con λ).

Problema Contextualizado de Selectividad
Traducción del enunciado al lenguaje matricial

«En una empresa se fabrican tres tipos de piezas A, B y C. En total se producen 100 piezas al día. El número de piezas de tipo A excede en 10 a las de tipo B. Si el coste de fabricar cada pieza es de 2 €, 3 € y 5 € respectivamente, y el gasto total diario es de 310 €, ¿cuántas piezas de cada tipo se producen?»

1. Asignación de incógnitas:
x = piezas tipo A,   y = piezas tipo B,   z = piezas tipo C

2. Planteamiento de ecuaciones:
• Total piezas: x + y + z = 100
• Relación A y B: x = y + 10 ➔ x - y = 10
• Coste total: 2x + 3y + 5z = 310

3. Resolución por Gauss / Cramer:
Resolviendo el sistema obtenemos directamente:
x = 50 piezas de tipo A
y = 40 piezas de tipo B
z = 10 piezas de tipo C
