El concepto de límite describe el comportamiento de una función al aproximarse a un valor concreto o al infinito, sin necesidad de alcanzarlo. Es la base fundamental para el cálculo de asíntotas, la continuidad y la derivada.

Comportamiento Asintótico y Límites Laterales

Observa la función racional f(x) = x + 1x - 2. Alrededor de x = 2 el denominador se anula (k0), disparando las ramas al infinito. Al alejarse hacia ±∞, los valores se estabilizan en la recta horizontal.

Curva f(x) = (x+1)/(x-2) Asíntota Vertical: x = 2 Asíntota Horizontal: y = 1
Asíntota Vertical (A.V.)
Candidatos: puntos que anulan el denominador (x - 2 = 0 ➔ x = 2)
Estudiamos los límites laterales evaluando valores cercanos:
• Por la izquierda: lim (x ➔ 2⁻) x + 1x - 2 = 30⁻ = -∞  (ej: x = 1,99)
• Por la derecha:   lim (x ➔ 2⁺) x + 1x - 2 = 30⁺ = +∞  (ej: x = 2,01)

Como al menos un lateral da ±∞, existe una Asíntota Vertical en x = 2.
Asíntota Horizontal (A.H.)
Comportamiento en el infinito (x ➔ ±∞)
lim (x ➔ +∞) x + 1x - 2 = lim (x ➔ +∞) xx = 1
lim (x ➔ -∞) x + 1x - 2 = 1

Al dar un número real finito, existe una Asíntota Horizontal en y = 1 en ambos extremos.

Las 3 Indeterminaciones Básicas de Examen

Una indeterminación no significa que el límite no exista, sino que la sustitución directa no basta: hay que romperla algebraicamente.

Tipo 00 (Polinomios) ➔ Factorizar y simplificar
Ejemplo: lim (x ➔ 3) x² - 9x² - 2x - 3
1. Sustitución inicial: 3² - 93² - 6 - 3 = 00 (Indeterminación)
2. Como x = 3 anula ambos polinomios, factorizamos sacando el término (x - 3):
   • Numerador: x² - 9 = (x - 3)(x + 3)
   • Denominador: x² - 2x - 3 = (x - 3)(x + 1)
3. Cancelamos el factor problemático (x - 3):
   lim (x ➔ 3) (x - 3)(x + 3)(x - 3)(x + 1) = lim (x ➔ 3) x + 3x + 1
4. Evaluamos: 3 + 33 + 1 = 64 = 32
Tipo 00 con Raíces ➔ Multiplicar por el Conjugado
Ejemplo: lim (x ➔ 0) √x + 4 - 2x
1. Sustitución: √4 - 20 = 00
2. Multiplicamos numerador y denominador por el conjugado (√x + 4 + 2):
   Numerador: (√x + 4 - 2) · (√x + 4 + 2) = (x + 4) - 4 = x
3. Simplificamos la x del denominador:
   lim (x ➔ 0) xx · (√x + 4 + 2) = lim (x ➔ 0) 1√x + 4 + 2
4. Evaluamos: 1√4 + 2 = 12 + 2 = 14
Tipo ∞∞ ➔ Comparación de Grados
Para cocientes polinómicos lim (x ➔ ∞) P(x)Q(x):
• Grado P > Grado Q: El límite es ±∞ (no hay asíntota horizontal).
• Grado P = Grado Q: El límite es el cociente de los coeficientes líderes.
   Ejemplo: lim (x ➔ ∞) 5x² - 22x² + 7 = 52
• Grado P < Grado Q: El denominador crece mucho más rápido ➔ Límite = 0.

Continuidad y Cálculo del Parámetro k

Definición Rigurosa de Continuidad
Una función f(x) es continua en x = c si cumple 3 condiciones:
1. Existe imagen: f(c) ∈ ℝ
2. Existe límite: lim (x ➔ c⁻) f(x) = lim (x ➔ c⁺) f(x) = L
3. Coincidencia: lim (x ➔ c) f(x) = f(c)
Problema clásico de Selectividad: Hallar k para que f(x) sea continua en todo ℝ
f(x) = {
x² + k         si x < 2 3x - 1         si x ≥ 2
Paso 1: Identificar ramas y punto de cambio

Las dos ramas son polinomios (parábola y recta), por lo que son continuas por separado en sus intervalos. El único punto crítico donde puede haber un salto es en x = 2.

Paso 2: Calcular imagen y límites laterales en x = 2
• Imagen: f(2) = 3(2) - 1 = 6 - 1 = 5
• Límite por la izquierda (x < 2):
  lim (x ➔ 2⁻) (x² + k) = 2² + k = 4 + k
• Límite por la derecha (x > 2):
  lim (x ➔ 2⁺) (3x - 1) = 3(2) - 1 = 5
Paso 3: Igualar laterales para forzar la continuidad
Para que exista límite y coincida con f(2), los laterales deben coincidir:
lim (x ➔ 2⁻) f(x) = lim (x ➔ 2⁺) f(x)
4 + k = 5  ➔  k = 5 - 4  ➔  k = 1
Con k = 1, la función se conecta sin saltos en el punto (2, 5)
