Las Potencias y sus Propiedades

Comprende la multiplicación repetida, descubre por qué se suman los exponentes, y aprende la lógica de a⁰ = 1 y las potencias negativas.

Multiplicar el Mismo Número Muchas Veces
Una potencia es una forma abreviada de escribir una multiplicación repetida del mismo factor.
• Base (a): El número que se multiplica por sí mismo.
• Exponente (n): El número de veces que se repite la base.

Problema Visual: El Crecimiento Exponencial

Una bacteria se duplica en dos cada minuto. ¿Cuántas bacterias habrá al cabo de 3 minutos?

En solo 10 minutos habría 2¹⁰ = 1.024 bacterias. Las potencias crecen a un ritmo vertiginoso.

Las Dos Reglas de Oro
Cualquier número elevado a 0 es 1 (a⁰ = 1):

Demostración por división de potencias iguales:
aⁿ / aⁿ = aⁿ⁻ⁿ = a⁰
Pero cualquier cantidad dividida entre sí misma da 1: aⁿ / aⁿ = 1. Por tanto, ¡a⁰ = 1 obligatoriamente!

Exponentes Negativos (a⁻ⁿ = 1 / aⁿ):

Un exponente negativo no hace que el número sea negativo: simplemente le da la vuelta como una fracción (el inverso multiplicativo):
3⁻² = 1 / 3² = 1 / 9

⚠️ Cuidado con el Paréntesis y el Signo Menos:

• (-3)² = (-3) · (-3) = +9 (el cuadrado afecta a todo el paréntesis).
• -3² = -(3 · 3) = -9 (el cuadrado solo afecta al 3, el menos se queda fuera).

Simplificación Combinada de Expresiones

Ejemplo típico de examen: Simplifica dejando una sola potencia:

Operación inicial:
(2³ · 2⁴) · 2⁵ (2²)³
1. Arriba sumamos exponentes: 3 + 4 + 5 = 12 ➔ 2¹²
2. Abajo multiplicamos potencias: 2 · 3 = 6 ➔ 2⁶
Fracción simplificada: 2¹² 2⁶
3. Restamos exponentes del cociente: 12 - 6 = 6
➔ Resultado final = 2⁶ = 64
¿Qué hacer si tienen distinta base?
Caso 1: Tienen el mismo exponente

Se multiplican o dividen las bases y se deja el mismo exponente:
• 2³ · 5³ = (2 · 5)³ = 10³ = 1.000
• 12⁴ / 3⁴ = (12 / 3)⁴ = 4⁴ = 256

Caso 2: Bases factorizables (números compuestos)

Descomponemos en factores primos para conseguir bases iguales:
• 4³ · 2⁵ = (2²)³ · 2⁵ = 2⁶ · 2⁵ = 2¹¹
• 9² / 3³ = (3²)² / 3³ = 3⁴ / 3³ = 3¹ = 3

¡NO Existe Propiedad para Sumar o Restar Potencias!
2³ + 2² ≠ 2⁵ (¡ERROR GRAVE!)

Vamos a comprobarlo numéricamente:

• 2³ + 2² = 8 + 4 = 12
• 2⁵ = 2 · 2 · 2 · 2 · 2 = 32
¡12 no es igual a 32!

Las propiedades de sumar exponentes SOLO sirven para multiplicar.

¿Cómo se resuelve una suma o resta de potencias?
Método 1: Calcular cada una y operar

Si los números son pequeños, simplemente calcula cada potencia:
• 3³ - 2⁴ = 27 - 16 = 11
• 5² + 4² = 25 + 16 = 41

Método 2: Sacar Factor Común (Nivel 2º ESO)

Si las potencias tienen la misma base y exponentes grandes, extraemos la potencia menor como factor común:
• 2¹⁰ + 2⁸ = 2⁸ · (2² + 1) = 2⁸ · (4 + 1) = 5 · 2⁸
