2º Bachillerato (Ciencias y CCSS)
La inferencia estadística es la disciplina que permite deducir propiedades de una población entera a partir de una muestra reducida. Aprende a calcular intervalos de confianza para la media o proporción y a determinar el tamaño de muestra necesario para no superar un margen de error fijado.

Población, Muestra y Distribución de la Media

El Puente Estadístico: De la Parte al Todo
Población (Parámetros desconocidos) vs. Muestra (Estadísticos conocidos)

Casi nunca podemos encuestar a millones de ciudadanos ni analizar todos los productos de una fábrica. Tomamos una muestra aleatoria de tamaño n y calculamos su media x̄. La pregunta clave es: ¿cómo de cerca está esa media muestral de la media poblacional real μ?

Teorema Central del Límite (TCL)
Distribución de las Medias Muestrales

Si una población tiene media μ y desviación típica σ, al extraer todas las muestras posibles de tamaño n (con n ≥ 30 o población normal), las medias de esas muestras se comportan como una variable normal:

X̄ ~ N( μ,  σ√n )
• La media de todas las muestras coincide exactamente con la media real: μ_x̄ = μ.
• La dispersión de las medias (error estándar) es mucho menor que la individual: σ_x̄ = σ / √n.
(A mayor tamaño muestral n, las medias se concentran más apretadas en torno a μ).
Distribución para Proporciones Muestrales
¿Qué ocurre si la variable es una proporción (Sí/No, Votantes)?

Para una variable dicotómica con proporción poblacional de éxito p y fracaso q = 1 - p, la proporción en la muestra p̂ se distribuye como:

P̂ ~ N( p,  √p · qn )

Intervalos de Confianza para la Media Poblacional

El Nivel de Confianza (1 - α) y el Valor Crítico z_α/2
¿Qué significa un 95% de confianza?

Significa que si repitiéramos el muestreo 100 veces, 95 de los intervalos calculados contendrían la media real μ y 5 quedarían fuera. El nivel de significación o riesgo de error es α.

Nivel de Confianza (1 - α) Riesgo (α) Cola unilateral (α/2) Valor Crítico (z_α/2)
90% (0,90) 0,10 0,05 1,645
95% (0,95) [El estándar] 0,05 0,025 1,960
99% (0,99) 0,01 0,005 2,575
Fórmula del Intervalo de Confianza para μ
I.C. = [  x̄ - z_α/2 · σ√n ,   x̄ + z_α/2 · σ√n  ]
Problema Resuelto Paso a Paso (Tipo Examen)
«El tiempo de carga de una página web sigue una distribución normal con σ = 0,8 s. Una muestra aleatoria de n = 64 visitas da una media de x̄ = 3,5 s. Halla el I.C. al 95%.»
1. Extraer los datos del enunciado:
• Media muestral: x̄ = 3,5
• Desviación típica conocida: σ = 0,8
• Tamaño muestral: n = 64 ➔ √n = √64 = 8
• Confianza 95% ➔ z_α/2 = 1,96

2. Calcular el Margen de Error (E):
E = z_α/2 · σ√n = 1,96 · 0,88 = 1,96 · 0,1 = 0,196

3. Construir los extremos del intervalo [ x̄ - E , x̄ + E ]:
• Extremo inferior: 3,5 - 0,196 = 3,304
• Extremo superior: 3,5 + 0,196 = 3,696

Intervalo al 95%: [ 3,304 ; 3,696 ] segundos

Error Máximo Admisible y Tamaño de la Muestra

El Margen de Error Admisible (E)
La semiamplitud del intervalo de confianza

El radio del intervalo es la distancia desde la media muestral hasta cualquiera de los extremos:

E = z_α/2 · σ√n        (Amplitud total del intervalo = 2 · E)
Cálculo del Tamaño Muestral Mínimo (n)
Despejamos n elevando ambos miembros al cuadrado
√n = z_α/2 · σE     ➔     n = [ z_α/2 · σE ]²
⚠️ La Regla de Oro de Selectividad: Redondeo por Exceso
Jamás apliques redondeo simétrico en el tamaño muestral

Si n da con decimales (por ejemplo, 68,14), debes redondear obligatoriamente al entero superior más cercano (69). Si redondearas a 68, la muestra sería insuficiente y el error superaría el límite permitido.

Ejemplo guiado:
«Con σ = 12 y una confianza del 99% (z_α/2 = 2,575), ¿cuántas observaciones se necesitan para que el error máximo no supere 2 unidades (E = 2)?»

n = [ 2,575 · 122 ]² = [ 30,92 ]² = [ 15,45 ]² = 238,70

Solución final: Se necesitan como mínimo n = 239 observaciones.

Relaciones Matemáticas Observables
• Si aumentas la confianza (1 - α): El valor z sube ➔ El margen de error crece ➔ El intervalo se hace más ancho (menos preciso).
• Si aumentas el tamaño muestral (n): Al dividir por √n el error baja ➔ El intervalo se hace más estrecho (más preciso).
• Si aumenta la dispersión (σ): Crece la incertidumbre ➔ El intervalo se ensancha.
