Diagrama de Árbol y Teorema de la Probabilidad Total
«Avanzar hacia adelante en el tiempo»

Si un espacio se divide en ramas incompatibles A₁, A₂, ..., Aₙ, la probabilidad de un suceso final B es la suma de los productos de cada camino del árbol:

P(B) = P(A₁)·P(B|A₁) + P(A₂)·P(B|A₂) + ... + P(Aₙ)·P(B|Aₙ)
Teorema de Bayes: Probabilidad a Posteriori
«Ir marcha atrás: sabiendo el resultado final, ¿de qué rama procedía?»
P(Aᵢ|B) = P(Aᵢ ∩ B)P(B) = P(Aᵢ) · P(B|Aᵢ) ∑ [ P(Aₖ) · P(B|Aₖ) ] = Rama elegidaSuma de todas las ramas que dan B
Ejemplo clásico de examen (Control de Calidad):

Una fábrica usa dos máquinas: la Máquina 1 produce el 60% de los tornillos (con 2% de defectuosos) y la Máquina 2 el 40% (con 5% de defectuosos). Si se elige un tornillo al azar y es defectuoso (D), ¿cuál es la probabilidad de que lo fabricara la Máquina 1?

1. Ramas de defectuosos: P(M₁) = 0,60 ; P(D|M₁) = 0,02  |  P(M₂) = 0,40 ; P(D|M₂) = 0,05
2. Probabilidad Total de tornillo defectuoso P(D):
   P(D) = (0,60 · 0,02) + (0,40 · 0,05) = 0,012 + 0,020 = 0,032 (3,2%)
3. Aplicamos Bayes para P(M₁|D):
   P(M₁|D) = 0,60 · 0,020,032 = 0,0120,032 = 0,375 (37,5%)

Distribución Binomial: B(n, p)

Modela el número de éxitos k al repetir n ensayos independientes con probabilidad fija de éxito p (y fracaso q = 1 - p).

Función de Probabilidad Puntual y Parámetros
P(X = k) = nk · pᵏ · (1 - p)ⁿ⁻ᵏ          donde nk = n!k! · (n - k)!
• Media (Esperanza de aciertos): μ = n · p
• Varianza: σ² = n · p · q  ➔  Desviación típica: σ = √n · p · q
Ejemplo Modelo Resuelto: El Arquero Olímpico
«Un arquero profesional tiene una probabilidad de acertar en el centro de la diana del 80% (p = 0,8). Si dispara 5 flechas (n = 5), calcula:»
Identificamos la variable: X = "número de flechas que dan en el centro" ~ B(n = 5, p = 0,8)
Datos: n = 5,  p = 0,8,  q = 1 - 0,8 = 0,2

Apartado A: Probabilidad de acertar exactamente 4 flechas (k = 4):
P(X = 4) = 54 · (0,8)⁴ · (0,2)⁵⁻⁴
• Calculamos el combinatorio: 54 = 5!4! · 1! = 5 · 4 · 3 · 2 · 1(4 · 3 · 2 · 1) · 1 = 5
• Multiplicamos potencias: P(X = 4) = 5 · (0,4096) · (0,2) = 0,4096 (40,96%)

Apartado B: Probabilidad de acertar AL MENOS una flecha (P(X ≥ 1)):
¡Truco de examen! En lugar de calcular P(1)+P(2)+P(3)+P(4)+P(5), usamos el suceso contrario (no acertar ninguna flecha, X = 0):
• P(X = 0) = 50 · (0,8)⁰ · (0,2)⁵ = 1 · 1 · (0,00032) = 0,00032
• P(X ≥ 1) = 1 - P(X = 0) = 1 - 0,00032 = 0,99968 (99,97%)

Apartado C: ¿Cuántas flechas se espera que acierte en promedio?
• Media: μ = n · p = 5 · 0,8 = 4 flechas

Distribución Normal N(μ, σ), Tabla y Casos de Examen

La Campana de Gauss y el Cociente Intelectual (CI)
Teorema Central del Límite: Suma de múltiples factores independientes

Cualquier fenómeno biológico, antropométrico o social que dependa de muchos factores aleatorios pequeños converge hacia una distribución normal. Por ejemplo, el Cociente Intelectual (CI) está calibrado para que la media poblacional sea μ = 100 y la desviación típica sea σ = 15 ➔ CI ~ N(100, 15).

💡 Dato metodológico: Para poblaciones completas o muestras grandes (N ≥ 30) la campana de Gauss es el estándar. Si la muestra experimental es pequeña (N < 30) y no conocemos la varianza real de la población, se recurre a la distribución t de Student.
Paso Obligatorio: Tipificación
Convertir X en Z para poder consultar la tabla estándar tabulada N(0, 1)
Z = X - μσ
¿Qué significa y cómo se lee la Tabla N(0, 1)?
La tabla da el área acumulada hacia la izquierda de valores positivos: Φ(z) = P(Z ≤ z)

En las filas buscas las unidades y el primer decimal; en las columnas buscas las centésimas (segundo decimal):

z 0.00 ... 0.04 ...
1.9 0.9713 ... 0.9738 ...
2.0 0.9772 ... 0.9793 ...
Ejemplo: Para z = 2,00 ➔ fila 2.0 y columna 0.00 ➔ P(Z ≤ 2,00) = 0,9772 (el 97,72% de la población queda por debajo).
Problema Modelo Resuelto: Superdotación Intelectual (CI)
«Si el CI sigue una distribución N(100, 15), ¿qué porcentaje de personas tiene un CI ≥ 130 (altas capacidades)?»
Variable original: X ~ N(μ = 100, σ = 15). Buscamos calcular P(X ≥ 130).

1. Tipificar la variable para pasar a Z ~ N(0, 1):
Z = X - μσ = 130 - 10015 = 3015 = 2,00
Por tanto: P(X ≥ 130) = P(Z ≥ 2,00)

2. Aplicar complementario (la tabla solo lee áreas hacia la izquierda "≤"):
P(Z ≥ 2,00) = 1 - P(Z ≤ 2,00)

3. Consultar la tabla para z = 2,00:
P(Z ≤ 2,00) = Φ(2,00) = 0,9772

4. Resultado final:
P(X ≥ 130) = 1 - 0,9772 = 0,0228 ➔ 2,28%

Conclusión: Solo el 2,28% de la población mundial alcanza o supera un CI de 130.

Chuleta Mnemotécnica de Simetrías
1. P(Z ≤ a): Buscar directamente a en la tabla ➔ Φ(a).
2. P(Z ≥ a): El área total bajo la curva es 1 ➔ 1 - Φ(a).
3. P(Z ≤ -a): Por simetría axial respecto al centro ➔ P(Z ≥ a) = 1 - Φ(a).
4. P(Z ≥ -a): Área complementaria de la cola negativa ➔ 1 - P(Z ≤ -a) = Φ(a).
5. P(a ≤ Z ≤ b): Restar el acumulado del mayor menos el del menor ➔ Φ(b) - Φ(a).

Teorema de De Moivre y Corrección de Continuidad (Yates)

¿Cuándo se puede aproximar? (Condiciones de De Moivre)
Si n es grande y p no es extremo, la Binomial se curva como una campana
Requisitos indispensables en examen:
1. n ≥ 30 (o número elevado de ensayos)
2. n · p ≥ 5
3. n · q ≥ 5 (donde q = 1 - p)

Si se cumplen, aproximamos: X ~ B(n, p)  ➔  X' ~ N(μ = n·p,  σ = √n·p·q)
¿Por qué es obligatoria la corrección de medio punto (± 0,5)?
El choque conceptual entre el mundo discreto y el mundo continuo

En una distribución continua como la Normal, la probabilidad en un punto exacto es nula: P(X' = k) = 0 (una línea vertical no tiene área). Sin embargo, en la Binomial discreta, el suceso X = k tiene la anchura de una barra que va desde k - 0,5 hasta k + 0,5.

Reglas de ajuste de Yates:
• Probabilidad puntual: P(X = k)  ➔  P(k - 0,5 ≤ X' ≤ k + 0,5)
• Menor o igual: P(X ≤ k)  ➔  P(X' ≤ k + 0,5)  (incluye toda la barra de k)
• Estrictamente menor: P(X < k)  ➔  P(X' ≤ k - 0,5)  (excluye la barra de k)
• Mayor o igual: P(X ≥ k)  ➔  P(X' ≥ k - 0,5)  (incluye toda la barra de k)
• Estrictamente mayor: P(X > k)  ➔  P(X' ≥ k + 0,5)  (excluye la barra de k)
