Un vector describe un cambio
Un vector puede representar un desplazamiento, una velocidad o una fuerza. Sus componentes dicen cuánto cambia cada coordenada: v = (vₓ, vᵧ).

Tres pistas para leer una flecha
Punta = inicio + componentes
X horizontal · Y vertical
🧭La dirección describe la inclinación de la recta; el sentido indica hacia dónde apunta la flecha.
¿Cuánto mide la flecha?
Las componentes forman los catetos de un triángulo rectángulo. El módulo es la hipotenusa: |v| = √(vₓ² + vᵧ²).

📏El módulo nunca es negativo. Cambiar el signo de una componente refleja el triángulo, pero no cambia las longitudes de sus lados.
