📋 Fórmulas para desarrollo rápido y factorización de polinomios sin pasar por multiplicaciones largas.
🔲 1. Las 3 Clásicas (Cuadrados de Binomios)
Identidad Fórmula General Ejemplo Práctico
Cuadrado de una Suma (a + b)² = a² + 2ab + b² (x + 3)² = x² + 6x + 9
Cuadrado de una Diferencia (a − b)² = a² − 2ab + b² (2x − 5)² = 4x² − 20x + 25
Suma por Diferencia (a + b)(a − b) = a² − b² (3x + 4)(3x − 4) = 9x² − 16
🧊 2. Cubos de Binomios y Factorización de Cubos
Identidad Fórmula General Ejemplo Práctico
Cubo de una Suma (a + b)³ = a³ + 3a²b + 3ab² + b³ (x + 2)³ = x³ + 6x² + 12x + 8
Cubo de una Diferencia (a − b)³ = a³ − 3a²b + 3ab² − b³ (x − 1)³ = x³ − 3x² + 3x − 1
Suma de Cubos a³ + b³ = (a + b)(a² − ab + b²) x³ + 8 = (x + 2)(x² − 2x + 4)
Diferencia de Cubos a³ − b³ = (a − b)(a² + ab + b²) x³ − 27 = (x − 3)(x² + 3x + 9)
⭐ 3. Trinomios y Simplificación Rápida
Identidad Fórmula General Ejemplo Práctico
Cuadrado de un Trinomio (a + b + c)² = a² + b² + c² + 2ab + 2ac + 2bc (x + y + 2)² = x² + y² + 4 + 2xy + 4x + 4y
Identidad de Legendre (a + b)² + (a − b)² = 2(a² + b²) (x + 3)² + (x − 3)² = 2(x² + 9) = 2x² + 18
Identidad de Legendre (Resta) (a + b)² − (a − b)² = 4ab (x + 2)² − (x − 2)² = 4 · x · 2 = 8x
🔺 4. Triángulo de Pascal (Coeficientes de (a + b)ⁿ)
Cada número es la suma de los dos que tiene justo encima. Da los coeficientes de cualquier binomio elevado a n:
n = 0: 1
n = 1: 1    1
n = 2: 1    2    1   ➔ a² + 2ab + b²
n = 3: 1    3    3    1   ➔ a³ + 3a²b + 3ab² + b³
n = 4: 1    4    6    4    1   ➔ a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴
