Potencial
(n ≠ −1)		 ∫ xⁿ dx = xⁿ⁺¹n + 1 + C ∫ u' · uⁿ dx = uⁿ⁺¹n + 1 + C ∫ 2x(x²+1)³ dx = (x²+1)⁴4 + C
Logarítmica
(n = −1)		 ∫ 1x dx = ln|x| + C ∫ u'u dx = ln|u| + C ∫ 2xx²+5 dx = ln|x²+5| + C

📐 3. Trigonométricas y Formas Tipo Arco

Seno ∫ cos x dx = sen x + C ∫ u' · cos u dx = sen u + C ∫ 3·cos(3x) dx = sen(3x) + C
Coseno ∫ sen x dx = −cos x + C ∫ u' · sen u dx = −cos u + C ∫ 2x·sen(x²) dx = −cos(x²) + C
